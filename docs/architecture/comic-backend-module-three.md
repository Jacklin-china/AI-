# Comic 模块三：故事组装与导出

本模块接通故事编排与导出材料两页。一个 Comic 引导聊天维护一个当前故事，明确选入同一聊天多个作品中已采用的图片，支持单图、重复用图、AI 初稿与人工编辑。交付视频制作文字和图片素材包，不接入视频生成。

## 领域边界与来源

`domains/comic/stories.py` 承担跨作品成图故事业务。它复用 `ComicMediaStore` 的媒体身份、请求认领和写入守卫，复用原作品修订表、Core Run/Event/Artifact、RuntimeManager 与现有文本/Vision 模型出口。既有单作品导演分镜保持原职责。没有新增业务表、供应商出口、依赖或执行框架。

聊天确定稳定 `story_id`。首次写入在同一 `BEGIN IMMEDIATE` 事务绑定宿主作品，并校验宿主版本；后续写入使用预期故事版本。图片候选读取实际采用版本；故事冻结图片 ID、版本、Artifact、SHA-256 和对应来源。换用最新版、取消采用或切换作品不会改写已存故事。跨聊天、非采用的新来源、文件缺失、哈希变化与失效 Artifact 均拒绝进入新修订。

AI 只接收本轮要求、明确选入图片的真实字节及逐图来源。直接上传不凭空继承作品 Brief；生成图读取原固定 Prompt 的来源，外部改图复用已确认修改范围与替代约束。各图来源分开传入，不推断不同图片为同一角色。模型语义核验列出镜头、字段、证据与冲突；没有新增中文关键词规则。

## 状态与接口

根路径为 `/api/comic/conversations/{id}/story`：

| 方法与路径 | 行为 |
| --- | --- |
| GET 根路径，支持 `?version=` | 当前或历史服务端快照、核验、确认、清单与导出记录 |
| GET `/images`、`/versions`、`/requests` | 已采用候选、故事历史、原请求执行状态与保留候选 |
| PUT 根路径 | 保存人工草稿，不调用模型 |
| POST `/generate`、`/review` | AI 初稿、独立一致性核验 |
| POST `/confirm` | 绑定版本、正文指纹与核验指纹；错误阻断，建议需明确接受 |
| POST `/restore`、`/adopt-candidate` | 历史恢复或保存已生成候选，均追加新修订 |
| POST `/exports` | 当前已确认版本的 ZIP，不调用模型 |

写请求包含唯一 `request_id`、`conversation_id`、`anchor_project_id`、`expected_project_version` 和 `expected_story_version`。同请求恢复原结果；已认领、已提交或结果未知的模型请求不能自动重发。模型结果落盘前重新核对版本，冲突保留 Run 中候选，不覆盖人工编辑；候选可直接保存为新版本。Shell 终态更新合并候选状态，并提供既有 error_id/trace_id。

手工编辑、换图、排序与恢复追加故事修订，新版不继承确认。再次核验也使旧核验指纹的确认失效。前端会话控制器由 `DirectorWorkspace` 持有，跨故事/导出页和同聊天作品切换共享；草稿自动串行保存，显示保存中、已保存、冲突和结果未知。晚到响应保留更新的本地修改，刷新通过服务端快照和原请求恢复。

## 导出格式与原子性

两个独立动作都基于同一已确认故事版本：复制视频制作文字；下载图片素材包。文字包含完整故事、镜头顺序、动作、运镜、时长、转场及文件名。

ZIP 使用 Python 标准库，包含 `story.md`、`manifest.json` 和 `images/`。图片使用原始 PNG/JPEG/WebP 字节和真实扩展名，相同图片版本只打包一次，镜头按清单引用。逐项校验来源文件、生命周期与哈希；缺图或改变列出受影响镜头并阻断，不省略素材。页面提供换图或回图片工作台重传入口。

RuntimeManager 原子写入后，再在同事务登记 Core DOCUMENT Artifact、故事导出修订和请求结果。写入、复核或登记失败回收本次文件，不生成成功记录。下载复用现有 Artifact 入口，并针对故事 ZIP 校验 active/ready、类型、文件与 SHA-256。

## 验收边界

离线行为测试覆盖来源归属与固定版本、自动保存与刷新、确认失效、历史恢复、并发绑定与版本冲突、重复请求、模型失败与晚到候选，以及真实格式 ZIP 解包、原字节、镜头顺序、重复用图、缺图、哈希变化、生命周期与原子失败。标准启动、页面验收和构建使用项目外自有隔离运行目录，退出清理。

真实模型验收复用 `scripts/verify_director_pipeline.py --suite story-export` 和原累计预算身份 `comic-backend-three-modules-20261012`，可用 `--additional-image` 明确添加同聊天其他作品图片。本次检查原账本不存在，因此未调用付费模型、未建立新账本；真实视觉/语义质量与供应商表现仍未验证。离线替身的通过不能描述为真实模型质量通过。

本模块保留用户数据、图片工作台和共享目录已有未提交修改，不整批提交或推送。
