# Comic 后端模块二：图片观察与外部改图闭环

范围：模块一与召回预算修复已由用户人工验收。用户授权模块二；旧残留永久删除受自动审批限制，用户明确选择保留清单并先开发模块二。本模块不修改前端、静态包、内部生图默认路径或视频，不启动 WorkBuddy 接力。

## 核心设计与复用

链路：显式分析图片 → 用户选择发现项/输入修改原文 → 原 Compiler 编辑模式 → 独立范围和约束核验 → 确认不可变指令 → 外部编辑并上传新版本 → 对比实际两图 → 用户选择最终版本。

- 领域新文件 `image_review.py` 只负责观察/编辑/对比契约。直接素材 Store 负责字节与版本，原 Prompt Compiler 负责提示词；这些契约不同，不能伪造 Shot 或把视觉流程塞进通用 Core。它没有供应商 SDK、独立数据库、任务引擎或费用服务。
- Shell 注入原 `core.llm.vision_chat` 和共享文本出口；Vision 增加兼容的 `single_attempt` 与用量回调。新路径每阶段只发送一次，旧调用默认重试策略保持原样。上传、GET、确认、选择不调用模型。
- 写入仍用 `ComicMediaStore`、`comic_entity_versions` 和同事务 Core Artifact。轻量 Run/Event/错误由原 `_comic_tracked_action` 提供。新模型请求在原 `media_request` 中原子认领，成功追加完成修订，失败保留 unavailable；重启/并发不能释放认领自动重发。
- 新测试文件验证真实文件、实际编译输入、两图像素、HTTP、刷新、并发和错误边界；没有把用户示例内容放进生产判断。新架构文档记录接口与验收，不另造框架。

## 观察、继承和修改范围

分析输入只包含明确目标图片、当前 Brief/本次任务、有效用户/固定资产约束、显式参考用途和对应真实图片。图片及参考分别核验所属作品/聊天、固定版本、Core Artifact 状态和原字节 SHA-256。相同版本参考不重复装配。不能从名字、上传动作、GET 或旧报告推断新内容。

报告冻结图片、任务、约束与参考快照哈希，保存模型与 `comic-image-review-1`。发现项数量可为零，各项包含公开观察、最小修改建议、置信度、不确定性和可选归一化区域。不强行凑检查项，不把观察或模型建议升级为用户事实，没有“自动通过”字段。失败/非法模型结构没有完成报告，不能解释为没有问题。

编辑入口必须明确图片版本、同一任务、报告身份、选中发现项 ID 和/或用户修改原文。未知 ID、旧任务、旧参考、变化的有效约束、跨聊天或已变化文件在编译前拒绝。未选发现项的观察与建议不会进入 Compiler；报告中建议保留的特征仍以建议身份传入。

用户本次修改原文进入 Run 的 `media_input`，通过模块一同一语义提取/独立核验得到有原文依据的临时编辑要求。指定文字沿用 exact/literal_value 契约，不按题材关键词识别。旧硬约束与本次修改冲突时停止，需要用户先纠正原要求，不能静默覆盖。普通语义表达允许准确改写；所有必需要求在模型调用前受既有容量检查和数量边界约束。

原 `StructuredImagePromptCompiler.compile_edit` 编写正向修改指令、负向约束与摘要；现有 `verify_prompt_constraints` 增加编辑范围输入，独立核验只改授权内容、准确覆盖要求且无矛盾。凭据绑定冻结内容和范围。没有新 PromptBuilder、假 Shot 或内部图片调用。指令以 Core PROMPT Artifact 和领域修订保存，历史不改写。

确认绑定该 Artifact 全内容指纹，GET 从同一确认修订投影真实状态。确认不是模型质量 pass，也不是费用批准。上传改图结果必须绑定指令的原图片版本及有效确认；同一图片链追加版本，不覆盖原字节，也不自动选中新版。

对比必须使用该指令绑定的原图和实际导入的新版本，发送两张真实图片及原显式参考。按选中修改项、用户原文（含已核验指定文字）与受保护特征/约束逐项返回 satisfied/not_satisfied/uncertain 和图像证据。遗漏、重复或新增核验 ID 拒绝保存完成报告。两版字节相同也允许如实对比，不假称已修改。对比不选择版本、不覆盖人工确认。

## 接口

公共写字段：`request_id`、`conversation_id`、`expected_project_version`。网络重试须保留整份原请求；同 ID 的不同参数拒绝。所有入口沿用 Studio 会话令牌和 Trace/Error 出口。

| 方法与路径（均在 `/api/comic/projects/{project_id}` 下） | 新字段 |
| --- | --- |
| POST `/image-analyses` | `image:{image_id,version}`、`task` |
| POST `/edit-instructions` | 上述 image/task；`analysis_artifact_id`、`selected_finding_ids`（可空）、`instruction`（可空，二者至少一项有内容） |
| POST `/edit-instructions/{artifact_id}/confirm` | `instruction_artifact_id` 必须等于 URL 身份 |
| POST `/image-comparisons` | `before`、`after`（均明确版本）、`instruction_artifact_id` |
| GET `/image-analyses[/{artifact_id}]` | `conversation_id` 查询参数 |
| GET `/edit-instructions[/{artifact_id}]` | 同上；恢复当前指令确认投影 |
| GET `/image-comparisons[/{artifact_id}]` | 同上 |

沿用模块一的 POST `/images` 导入结果：`parent` 指向原版本、`instruction_artifact_id` 指向已确认指令；同链还提供 `image_id`、`expected_image_version`。沿用 PUT `/api/comic/images/{image_id}/selection` 手动选择最终版本，独立校验 `expected_selection_version`。

列表有界返回最近 50 条，不自动调用模型；历史报告保持原冻结事实可读，下游使用时重新核验依据。没有新增请求体大小豁免；原图片上传仍为 5 MB 内 PNG/JPEG/WebP。
