# 04 · 里程碑计划（六周）

> 节奏纪律：每个里程碑 = 开 `feat/mX-主题` 分支 → 实现 → `ruff + pytest` 通过 →
> 更新 06 日志 → 合 `main` → 打 tag → 录 1 分钟演示（`assets/demo/`）。
> **演示视频是验收的一部分，没有演示不算完成。**

## 兼职周 0（第 1–2 周，与 M0/M1 并行）

目标：手动跑通 1–2 集漫剧，产出真实需求表。

- 跟教程全流程走一遍（推荐 B 站《即梦漫剧保姆级教程》2026 版）。
- 每一步**当场**填 `docs/05-兼职工作流记录表.md`（耗时 + 痛点）。
- 周末汇总：耗时 Top2 且可 Agent 化的环节 → 作为 M1/M2 的优先需求。
- 可选：在 AI 接单平台（塔猴等）接 1 个小单练手，以战代练；接单记录也填在 05。

## M0 · 跑通底座（第 1–2 天）→ Tag v0.1.0

- 任务：clone Open-LLM-VTuber 并独立运行；接国内 OpenAI 兼容 API（GLM）；配置二次元人设；
  按 docs/01 §1 初始化代码骨架（`uv sync && uv run pytest` 全绿）。
- 验收：与她语音对话 10 轮不翻车；底座版本号记入 docs/02。

## M1 · 分镜生成器（第 3 周）→ Tag v0.2.0

- 任务：`Tool` 协议落地；`generate_storyboard`：剧本 → 分镜 JSON → SQLite；
  通过底座把结果语音播报。
- 概念：Tool Calling + 结构化输出（structured_temperature=0.2）。
- 验收：300 字剧本 → 20 镜分镜表，字段完整率 100%；解析逻辑有单测；
  `evals/storyboard.jsonl` ≥10 条并产出第一份评测报告。

## M2 · Prompt 工厂 + 生图 + 预算（第 4 周）→ Tag v0.3.0

- 任务：人设卡数据模型；每镜拼接一致性 prompt；火山方舟生图接入；
  预算控制器 reserve/settle + 台账表。
- 验收：分镜表一键出图；预算超限时她语音拒绝并说明原因；台账记录每张图成本。

## M3 · VLM 质检 + 素材归档（第 5 周）→ Tag v0.4.0

- 任务：截图/图片批量质检（崩手/水印/人设跑偏）与评分；输出文件夹监听 → 归档打标。
- 验收：50 张人工标注一致率 ≥85%；"10 张里 7 张合格、3 张建议重做"的语音报告。

## M4 · 记忆 + 台账 + 评测（第 6 周）→ Tag v0.5.0

- 任务：项目记忆（人设卡库 + 历史问答）；素材库向量检索（sqlite-vec）；
  每集工时/成本统计报告。
- 验收：重启后能答对历史人设卡内容；单集工时对照 05 基线下降 ≥30%；
  docs/evals/ 汇总报告齐全。

  简历条目定稿（见 06 附录模板）。
