# M3 · 生图与预算工程验收（W4-R10）

日期：2026-09-12。运行环境：Windows、本项目 Python 环境、临时 SQLite、本地假供应商。

离线工程使用本地假供应商。用户配置官方 AK/SK 并明确授权最多 ¥0.30 后执行一次真实单镜调用；调用未返回供应商任务 ID或图片，账单状态未知，因此不记为成功或免费。

```powershell

```
