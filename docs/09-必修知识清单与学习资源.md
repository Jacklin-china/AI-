## 0 · 怎么用这份清单（纪律，比清单本身重要）

1. **一个知识点 = 1 个视频 + 官方文档**。看完**立刻**去写代码，禁止追更、禁止收藏夹吃灰。
2. **看完必须产出 30 分钟内能做完的东西**（每节都给你写好了"看完立刻做"）。没产出 = 没学会。
3. **视频与官方文档冲突时以文档为准**，发现冲突就回填文末「过时标记」表。
4. **全集类教程（600 集 / 200 集 / 748 集）一律只按目录跳看**，整刷 = 烂尾第一原因。
5. **视频总预算**：🔴必学 ≤ 8h，🟡必修 ≤ 3h，⚪加分 ≤ 1.5h，**合计 ≤ 12.5h**。超了就砍加分项。
