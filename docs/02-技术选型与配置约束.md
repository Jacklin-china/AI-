# 02 · 技术选型与配置约束（对标市面主流）

> 原则：**行业主流 + 国内可用云 API + 单机可跑（无独立显卡也能完成主线）+ 成本可控**。
> 所有可变参数落在 `config/settings.yaml`；本文档只回答"为什么这么选"。
> 模型型号以各平台控制台实际可用为准——换型号只改配置，不改代码。

## 1. 选型总表

| 类别 | 选型 | 为什么（市面对标） | 引入 |
|---|---|---|---|
| 语言 | Python 3.11–3.12 | Agent 生态兼容最好的区间；3.13+ 部分库未跟上 | M0 |
| 包管理 | uv | 事实上的新标准：快、锁 `uv.lock` 并提交 | M0 |
| 质量工具 | ruff + pytest | 当下最主流的 Lint/测试组合 | M0 |
| 数据模型 | pydantic v2 | 结构化输出/配置校验的行业标配 | M1 |
| LLM 接入 | OpenAI 兼容协议 | 一套代码随时换 GLM / DeepSeek / Qwen | M0 |
| 主力模型 | 智谱 GLM（对话）+ GLM-4V（视觉） | 国内直连、价格友好、对话与 VLM 同家省事 | M0/M3 |
| 备选模型 | DeepSeek（文本）/ Qwen-VL（视觉） | 比价与降级，切换只改配置 | 按需 |
| 存储 | SQLite（标准库 sqlite3） | 单机单用户零部署；台账与项目库同一个库 | M1 |
| 向量检索 | sqlite-vec（M4 再定） | 轻量无服务、与 SQLite 同库；数据量大再换 Chroma | M4 |
| 生图 | 火山方舟（即梦）API 为主；ComfyUI 本地为备 | 兼职主流工具即梦；本地备用防 API 变动 | M2 |
| Agent 底座 | Open-LLM-VTuber（MIT，独立运行） | Live2D/ASR/TTS/截图感知现成，我们只写"大脑" | M0 |
| 语音 | 底座 Edge TTS 起步 → GPT-SoVITS（可选） | 先跑通再追角色音色 | M5 |
| 台账看板 | SQLite + Markdown 报告 | 不引入 Web 框架，防范围膨胀 | M4 |

## 2. 底座集成边界（重要）

- Open-LLM-VTuber **独立 clone、独立运行**，实际版本号记录在下方；本仓库只通过其
  Agent/扩展接口接入。
- 禁止 fork 后修改底座核心——保证底座升级时我们零成本跟随。
- 分工：底座负责 Live2D 渲染、ASR/TTS、打断、截图采集；
  本仓库负责工具、记忆、预算、台账、质检。

> 底座版本记录：`待 M0 填写（commit hash + tag）`

## 3. 默认运行参数（改值只改 config，不改代码）

| 参数 | 默认值 | 说明 |
|---|---|---|
| temperature（自由对话） | 0.7 | 保留人设趣味 |
| structured_temperature（结构化） | 0.2 | 分镜 JSON 等要稳 |
| max_tokens | 2048 | |
| timeout_s | 30（LLM/HTTP）、60（生图） | |
| retry | 2，退避 2s/4s | |
| 生图日预算 | ¥5.0 | 兼职期红线；接单时可上调，但必须记台账 |
| token 日上限 | 200,000 | 防跑飞 |

## 4. 环境约束

- OS：Windows 10/11；仓库行尾 LF；全程 UTF-8。
- 硬件：主线全程走云 API，**无独立显卡可完成**；仅 ComfyUI 备用路线需 ≥8GB 显存。
- 网络：全部 API 走国内可直连端点；禁止把代理配置写死进仓库。
