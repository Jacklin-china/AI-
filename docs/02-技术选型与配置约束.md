# 02 · 技术选型与配置约束（对标市面主流）

> 原则：**行业主流 + 国内可用云 API + 单机可跑（无独立显卡也能完成主线）+ 成本可控**。
> 所有可变参数落在 `config/settings.yaml`；本文档只回答"为什么这么选"。
> 模型型号以各平台控制台实际可用为准——换型号只改配置，不改代码。

## 1. 选型总表

| 类别 | 选型 | 为什么（市面对标） | 引入 |
|---|---|---|---|
| 语言 | Python 3.11–3.12 | Agent 生态兼容最好的区间；3.13+ 部分库未跟上 | M0 |
| 包管理 | uv | 事实上的新标准：快、锁 `uv.lock` 并提交 | M0 |
| 质量工具 | ruff + pytest | 当下最主流的 Lint/测试组合 | M0 |
| 数据模型 | pydantic v2 | 结构化输出/配置校验的行业标配 | M1 |
| LLM 接入 | OpenAI 兼容协议 | 一套代码随时换 GLM / DeepSeek / Qwen | M0 |
| 主力模型 | **DeepSeek Chat**（OpenAI 兼容文本） | 主文本调用统一读取 `DEEPSEEK_API_KEY`；结构化输出与工具调用仍由 Core LLM 出口统一治理 | M0/M3 |
| 降级模型 | 智谱 **GLM-4.6** | 跨供应商才是真降级，主力不可用时自动切（`03` §9 风险 R4） | 按需 |
| 备选模型 | 混元 Hy4 preview（1M 上下文/慢思考/**无视觉**）、原有兼容模型 | 比价与特殊场景；切换只改 config/settings.yaml | 按需 |

| 生图 | 火山引擎即梦 Visual API（`volcengine-jimeng`，`high_aes_general_v40`） | 使用 `VOLC_ACCESSKEY` + `VOLC_SECRETKEY` 签名；适配器支持任务 ID、状态查询、费用回填；ComfyUI 只留 Future Work | W4 |

| 交互层 | CLI（必备）→ Gradio（可选）→ VTuber（可选） | 可插拔 `InteractionShell`，主线不依赖任何 UI | W1 |
| 语音 | 底座 Edge TTS 起步 → GPT-SoVITS（可选） | 先跑通再追角色音色 | W10 |
| 台账看板 | SQLite + Markdown 报告 | 不引入 Web 框架，防范围膨胀 | M4 |
| 工具协议 | MCP（Model Context Protocol） | 2026 事实标准；同一组工具自己能用、外部客户端也能用 | W8 |

## 2. 底座集成边界（重要，2026-09 已修订）

- Open-LLM-VTuber **独立 clone、独立运行**，实际版本号记录在下方；本仓库只通过其
  Agent/扩展接口接入。
- 禁止 fork 后修改底座核心——保证底座升级时我们零成本跟随。
- 分工：底座负责 Live2D 渲染、ASR/TTS、打断、截图采集；
  本仓库负责工具、记忆、预算、台账、质检。

> ⚠️ **2026-09 重要变更**：官方已宣布 **v2.0 为全量重写（complete rewrite），v1 进入 feature-frozen**
> （只修 bug，不接新需求），长期记忆功能已临时移除。
> 因此本仓库**不再把底座作为前置依赖**：主线全程 headless（CLI），
> 底座降级为 **W10 可选交互外壳**（见 `03` §4）。**接不上不影响任何里程碑验收。**
> 替代的早期交互层：`shells/cli.py`（必备）→ `shells/gradio_app.py`（可选）。

> 底座版本记录：`待 W10 填写（commit hash + tag，若接入）`

## 3. 默认运行参数（改值只改 config，不改代码）

| 参数 | 默认值 | 说明 |
|---|---|---|
| temperature（自由对话） | 0.7 | 保留人设趣味 |
| structured_temperature（结构化） | 0.2 | 分镜 JSON 等要稳 |
| max_tokens | 2048 | |
| timeout_s | 30（LLM/HTTP）、60（生图） | |
| retry | 2，退避 2s/4s | |
| 供应商专用请求体 | 默认 `{}` | 只在 YAML 配置；例如 DeepSeek 可用它关闭默认思考，主/备用供应商分别配置 |
| 生图日预算 | ¥20.0 | 当前单条视频硬上限；同日只允许一个视频批次，费用更低时不主动花满 |
| 预算账期 | UTC+8 | 按北京时间自然日统计单日预算；只改 YAML，不依赖操作系统时区数据库 |
| 生图项目/单集预算 | ¥20.0 / ¥20.0 | 当前一个项目、一集均对应一条视频，任一层先触顶就停止 |
| 生图单镜预算 | ¥1.0 | 普通图按 ¥0.30/次保守预占，单镜最多容纳约 3 次；返工仍需人工确认 |
| 生图预估单价 | ¥0.10/积分、3 积分/次 | 来自用户 2026-09-12 提供的即梦客户端截图上界，只用于预占，不冒充 API 实扣 |
| token 日上限 | 200,000 | 防跑飞 |

配置模板已启用单日/项目/单集/单镜四级预算和并发上限。用户截图显示普通图片约 1–3 积分/张、1 积分约 ¥0.08–0.10；为避免低估，当前预占取区间上界，即 ¥0.30/次。即梦客户端会员/充值积分与火山引擎官方 API 资源包并非已核实的同一计费账户，真实 API 返回金额前不得把预估值记成实扣；价格变化只改配置。官方 API 当前公开活动价格也只作交叉核对，不写死进代码：[即梦 AI API 活动页](https://www.volcengine.com/activity/jimeng)。

## 4. 环境约束

- OS：Windows 10/11；仓库行尾 LF；全程 UTF-8。
- 硬件：主线全程走云 API，**无独立显卡可完成**；仅 ComfyUI 备用路线需 ≥8GB 显存。
- 网络：全部 API 走国内可直连端点；禁止把代理配置写死进仓库。
