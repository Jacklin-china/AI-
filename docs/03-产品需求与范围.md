# 03 · 产品需求与范围

## 一句话目标

一个住在桌面、有二次元人设与音色的副导演 Agent：AI 漫剧兼职流程中帮我拆分镜、
守人设一致性、盯生图质检、管素材与成本台账——兼职喂需求，Agent 压工时。

## 用户与场景

- 主用户：我自己（AI 漫剧兼职创作者，Windows 单机，成本敏感）。
- 次用户（M4 后考虑）：兼职团队/社群里的其他漫剧创作者。

## P0（必须做，对应 M1–M4）

1. **分镜生成器**：剧本文本 → 分镜 JSON（镜号/画面描述/台词/运镜/秒数），可存可改。
2. **人设卡 Prompt 工厂**：角色卡（外貌/服装/风格 token）→ 每镜拼接一致性生图 prompt。
3. **生图编排 + 预算控制**：分镜表 → 生图任务；调用前查预算；台账记账到镜号。
4. **VLM 质检**：生成图 → 崩坏/水印/人设跑偏判定与评分 → 语音播报 + 标记重做。
5. **素材归档**：监听输出文件夹 → 重命名/打标/入库，可按集数/角色/镜头检索。
6. **项目记忆与台账**：人设卡库、历史问答记忆、每集工时与成本统计。

## P1（有余力再做）

台词→配音（GPT-SoVITS）、产值周报、极简 Web 看板。

## 明确不做（冻结清单，任何会话不得实现）

- 自动操作电脑 / UI 自动化（Computer Use）
- 自动剪辑成片、全自动无人生成流水线
- 多 Agent 框架（LangGraph/AutoGen 等）与"通用助手"类功能
- QQ/微信/Telegram 机器人端、手机端
- 爬取平台数据、绕开官方付费 API 的任何尝试

> 定位理由：全自动流水线是公司级产品（知漫剧、漫剧工坊等）的战场；
> 本项目的差异化是**人机协作缝隙**——按我的审美迭代、盯质量、记账、有情绪价值。

## 成功指标（M4 验收用，数值对照 docs/05 基线）

- 单集制作工时下降 ≥30%
- 质检可用：人工标注 50 张，与 Agent 判定一致率 ≥85%
- 分镜采纳率：条目不经修改直接可用 ≥70%
- 成本可视：每集生图成本台账误差 ≤10%
