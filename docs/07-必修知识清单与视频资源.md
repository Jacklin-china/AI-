# 07 · 必修知识清单与视频资源（B 站）

> 三条使用纪律（比清单本身重要）：
> 1. **每个知识点只允许"1 个入门视频 + 官方文档"**，看完立刻回到里程碑写代码；
>    禁止追更系列全集、禁止收藏夹吃灰——视频只负责带你入门，官方文档才是事实标准。
> 2. **视频会过时，代码永不过时**：每个知识点列了"重搜关键词"，发现视频太旧就按模板重搜，
>    B 站搜索结果里用"最新/2025/2026"关键词 + 按播放量排序筛选。
> 3. **看完必须产出**：要么一个能跑的 demo commit，要么 06 日志一行。没有产出 = 没学会。
>
> 全项目看视频总预算：**≤ 12 小时**（各条已标注）。

## 视频选型与更新的通用方法

1. **判断"大牛"的三个信号**：播放/点赞比正常、评论区有技术讨论（不是清一色"求资料"）、
   UP 主主页持续更新该领域。
2. **时效判断**：标题/简介带 2025/2026、讲的是当前版本（uv/GPT-SoVITS V4/即梦新界面）。
3. **过时兜底**：任何视频与官方文档冲突时，以文档为准，并回填本清单（打 tag 重搜）。
4. 每完成一个 K 点：在下方打卡表登记，作为 06 日志的附件证据。
