# kantoku-agent · 监督酱（AI 漫剧副导演）

> 一个住在桌面、有二次元人设与音色的**副导演 Agent**：在我兼职制作 AI 漫剧时，帮我拆分镜、
> 守人设一致性、盯生图质检、管素材与成本台账。
>
> 双线咬合：**Agent 项目开发（简历主线） × AI 漫剧兼职（真实应用场景）**——
> 兼职喂给 Agent 真实需求与数据，Agent 反过来压兼职工时。

## 架构（示意）

```
 Live2D 人设 + 角色音色（Open-LLM-VTuber 底座自带，独立运行）
        │  语音 / 文字 / 截图
 对话调度（本仓库 agent/）
        │
 ┌──────┴──────── 工具层 tools/（手写 function calling）──────┐
 │ ①分镜生成器  ②人设卡Prompt工厂  ③预算控制器               │
 │ ④素材归档    ⑤产值台账                                    │
 └──────────────────────────────────────────────────────────┘
 perception/  截图 VLM 质检（崩手/水印/人设跑偏 → 评分 → 语音播报）
 memory/      项目记忆 + 素材库向量检索
 data/        SQLite（项目库/台账）+ 日志（git 忽略）
```

## 快速开始

> 本仓库刻意**不含现成实现代码**——代码由里程碑过程逐步产出（docs/04），
> git 提交历史本身就是"从规范到产品"的学习记录，也是面试素材。

- 已就绪：全套规范（docs/）、配置模板（config/）、工具链约束（pyproject.toml）。
- M0 起步：安装 uv → `uv sync` 安装工具链 → 复制配置模板 → 填 `.env` → 独立 clone 底座 Open-LLM-VTuber。
- 第一次写代码：从 `docs/01-开发规范.md` 开始；使用 AI 协作时，会话入口是 `AGENTS.md`。
