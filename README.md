# kantoku-agent · 监督酱（AI 漫剧副导演）

> 一个**副导演 Agent**：在 AI 漫剧兼职流程中帮我拆分镜、守人设一致性、盯生图质检、
> 管素材与成本台账。
>
> 双线咬合：**Agent 项目开发（简历主线） × AI 漫剧兼职（真实应用场景）**——
> 兼职喂给 Agent 真实需求与数据，Agent 反过来压兼职工时。

## 架构 v2

```
 shells/  可插拔交互层：CLI（W1 起） → Gradio（可选） → VTuber（W10 可选）
        │  文字 / 语音 / 截图
 agent/  loop.py 手写 ReAct 内核  +  graph.py 显式状态机 + checkpoint
        │  context.py 按镜号裁剪上下文（Context Engineering）
 ┌──────┴──────── 工具层 tools/（手写 function calling）──────┐
 │ ①分镜生成器  ②上下文/Prompt 工厂  ③预算控制器              │
 │ ④素材归档    ⑤成本台账            ⑥VLM 质检                │
 └──────────────────────────────────────────────────────────┘
 core/    llm.py（超时/重试/降级）· tracing.py · budget.py
 perception/  图片 VLM 质检（二元判定 + 一致性打分 → 重做队列）
 memory/      人设卡库 + 素材库混合检索（FTS5 + sqlite-vec）
 mcp_server.py  同一组工具 → 也可被 Claude Code / Cursor 调用
 data/        SQLite（项目库/台账/trace）+ 日志（git 忽略）
```

**四条架构原则**：交互层可插拔 · 内核手写不依赖框架 · 工具一次实现两处可用 · trace 从头落。

## 快速开始

> 本仓库刻意**不含现成实现代码**——代码由里程碑过程逐步产出（见 `docs/03`），
> git 提交历史本身就是"从规范到产品"的学习记录，也是面试素材。

- 已就绪：全套规范（docs/）、配置模板（config/）、工具链约束（pyproject.toml）。
- W1 起步：装 uv → `uv sync` → 复制配置模板 → 填 `.env` → **先跑 CLI，不要碰底座**。
- 第一次写代码：从 `docs/04-功能开发引导.md` 的 §0 进度指针开始；使用 AI 协作时，会话入口是 `AGENTS.md`。
